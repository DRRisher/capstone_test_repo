      ImageIT3D + LaunchIT3D

      A two-application pipeline that takes non-technical sellers from a 3D model idea to a marketplace-ready listing. Capstone project, Southeast Missouri State University.

      ImageIT3D handles conversational design and model generation. LaunchIT3D handles printability analysis, marketplace copy, price guidance and the seller package export.

      Team: Austin Ray, Caleb Palmer, Alec Burke, Kaitlynn Hoffenberger, Dillen Risher.

      Prototype notes

      • Built-in shapes use parametric product templates (vessels, tags, stands) chosen and tuned by the assistant. Raised letters can be added to any of them.
      • Detailed AI models can be generated through the Meshy panel when the local server has a valid Meshy API key, or imported as STL, OBJ or GLB files.
      • Fees, print time and filament use are estimates. Check current marketplace fees before listing.
      • Your work is saved locally. Sign in to sync app settings and listing data to your Supabase account. Imported mesh geometry remains local to this browser.
